## 🧩 Sobre mí

Construyo el software con el que las empresas operan — módulos de gerencia y gestión, desde levantar el requerimiento hasta el modelo de datos, la lógica de negocio y la pantalla en la que el usuario termina trabajando todos los días.

Me gusta quedarme cerca del dato: diseñar el modelo, escribir las consultas y convertir el resultado en reportes y visualizaciones con los que alguien no técnico pueda decidir.
